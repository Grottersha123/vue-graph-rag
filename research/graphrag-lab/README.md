# Graph RAG Lab — учусь на своих данных VEU

Цель: глубоко понять Graph RAG на собственном онбординг-корпусе VEU.
Формат: пошаговые эксперименты, которые я запускаю сама; ИИ объясняет концепции по запросу.
Стек: LadybugDB 0.20.2 (embedded Cypher + vector index, наследник Kùzu) — тот же стек, что у VEU.
Данные: `onboarding-llm-wiki/sources/*.md` (17 файлов) + `veu-graph-mvp.json` (98 узлов, 177 рёбер).

Ритм: сессии по 30–60 минут. Один шаг = один понятный результат.

## Структура папки

- `SETUP.md` — как поднять окружение (уже работает, проверить командой из шага 0).
- `steps/` — по одному файлу на шаг: задача, что сделать, что должно получиться, вопросы себе.
- `experiments/` — мои скрипты и заметки к каждому шагу.
- `lab.duck` — база LadybugDB (создастся на шаге 1; в git не класть).
- `FINDINGS.md` — журнал: дата, шаг, что увидела, что удивило.

## Дорожная карта

- [ ] **0. Окружение** — `.venv` с LadybugDB, smoke-test Cypher (30 мин).
- [ ] **1. Граф в базу** — залить `veu-graph-mvp.json`: таблицы Process/Document/System/Source + рёбра. Прогнать первые MATCH-запросы (60 мин).
- [ ] **2. Чанки** — нарезать markdown на чанки ~500 токенов, таблица Chunk + ребро HAS_CHUNK от Document (60 мин).
- [ ] **3. Векторы** — эмбеддинги чанков, VECTOR индекс, семантический поиск без графа (60 мин). Это «обычный RAG» — база для сравнения.
- [ ] **4. Гибрид** — тот же вопрос через вектор + расширение по рёбрам графа. Сравнить ответы (60–90 мин). Сердце курса.
- [ ] **5. Мульти-хоп** — вопросы, где ответ через 2–3 ребра (например: «какие файлы нужны на этапе CV и какие из них зависят от Dolphin?»). Plain RAG здесь слабый — убедиться самой (60 мин).
- [ ] **6. Оценка** — 5–10 вопросов с эталонами, посчитать hit/miss для вектора vs гибрида (60 мин).
- [ ] **7. Выводы** — что дало граф, что было лишним; записать в FINDINGS.md.

## Принципы

- Каждый шаг оставляет рабочий артефакт: скрипт + наблюдение в FINDINGS.md.
- Если шаг не сошёлся с ожиданием — это находка, а не провал: записать почему.
- Секреты и чувствительные источники в базу не грузятся (политика вики).
