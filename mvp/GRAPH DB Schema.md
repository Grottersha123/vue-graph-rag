# VEU — Graph RAG Database Schema v5

Упрощённая схема базы данных Knowledge Graph: обязательное ядро и необязательное обогащение.

Цветные блоки и связи — обязательное ядро. Серые блоки и связи — optional и могут отсутствовать.

Предыдущая версия архитектуры: [[VEU — Graph RAG Architecture v4]].

Связанная модель данных: [[VEU — схема графа знаний для RAG v3]].

## Как читать схему

- Ядро: `SourceType → Document → DocumentVersion → Chunk → Embedding`.
- Серые связи (`DESCRIBES`, `FOR_ROLE`, `LINKS_TO` и другие) необязательны.
- Документ может быть связан с нулём, одним или несколькими процессами.
- Обычная ссылка не считается обязательной зависимостью. `REQUIRES` можно добавить позже как отдельное необязательное расширение.
