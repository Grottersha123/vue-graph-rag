# Relations

## Назначение

Ручное добавление и удаление поддерживаемых графовых связей в session snapshot.

## Поля и действия

- `Relation type`: один из вариантов `RelationKind`.
- `Exact source ID`: точный ID исходного узла.
- `Exact target ID`: точный ID целевого узла.
- `Add`: добавляет связь.
- `Delete`: удаляет связь.

Обе кнопки активны при валидном runtime и двух непустых ID. Операция проверяет точные ID и инварианты графа. Успех помечает snapshot dirty и сбрасывает активную DB.

## Вывод

Таблица показывает пользовательские связи `LINKS_TO`, `DESCRIBES` и `FOR_ROLE`. Изменения существуют только в session snapshot до публикации нового dump.
